# AI-Enabled Visa Status Prediction and Processing Time Estimator

## Milestone 1: Data Collection & Preprocessing

This repository contains the work completed for Milestone 1 of the project.

### Key Highlights
- Collected visa recommendation dataset from Kaggle
- Dataset size: 120,000 rows and 21 columns
- Removed irrelevant identifier columns
- Corrected data types for numeric features
- Handled missing values and inconsistencies
- Applied domain-based imputation for intended duration
- Saved cleaned dataset for further modeling

### Files
- `notebooks/data_preprocessing.ipynb` – Preprocessing notebook
- `data/processed/visa_recommendation_cleaned.csv` – Cleaned dataset
